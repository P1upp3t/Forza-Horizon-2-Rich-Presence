# Forza Horizon 2 — Discord Rich Presence

Votre voiture, votre course et votre aventure Horizon, sur Discord.

<p align="center"><a href="https://ko-fi.com/puppetzim"><img src="https://ko-fi.com/img/githubbutton_sm.svg" alt="Soutenir sur Ko-fi" height="52" /></a></p>

Application Windows gratuite qui affiche sur Discord votre activité dans Forza Horizon 2 pour Xbox One, exécuté via Azimuth. Toutes les fonctions sont gratuites ; les dons sont facultatifs. Le code source est privé.

## Fonctionnalités

- Vignette du véhicule avec nom, année, classe et indice de performance intégrés à l’image.
- La carte est recréée à chaque sélection, même du même véhicule. La peinture et les jantes dépendent de la vignette enregistrée par le jeu.
- Région approximative, classement, tours et progression des sprints avec deux décimales.
- Icônes pour carte, mode photo, pause, Festival, garage, améliorations, peinture et Autoshow.
- Ouvrez azimuth.exe depuis l’application : Launch FH2 + Presence démarre le lanceur et la présence ensemble.
- Interface inspirée de Horizon, neuf langues et lecture locale à 1, 2 ou 4 Hz.

## Installation

1. Téléchargez le ZIP avec le lien en haut, puis extrayez rich-presence à côté de azimuth.exe.
2. Ouvrez Discord pour ordinateur et connectez-vous.
3. Lancez FH2 Presence.exe, puis choisissez Start Presence ou Launch FH2 + Presence.
4. Pour publier des cartes personnalisées, activez Automatic Thumbnails dans Preferences.

Nécessite Windows 10/11 x64, Microsoft Edge WebView2 et votre installation du jeu. Python, mot de passe et jeton Discord ne sont pas nécessaires.

## Confidentialité et compatibilité

L’envoi des images est désactivé par défaut. Si vous l’activez, seules les cartes des véhicules sont envoyées à Uguu sous forme de PNG publics et temporaires. Les sauvegardes, journaux et base du joueur ne sont pas envoyés. L’application ne modifie ni la mémoire ni les sauvegardes. Les traductions sont locales ; les images et icônes peuvent utiliser des services externes.

FH2 1.0.0.64 : utilisez v1.0.0 avec Azimuth 0.9.7 ou v1.1.0 avec Azimuth 0.9.9. Avec 0.9.9, le véhicule, la classe/l’indice, la vignette, la région, la pause et le monde ouvert sont confirmés ; les courses restent à revérifier. Discord impose un intervalle minimum de 15 secondes entre les envois ; son cache peut retarder les images. Les régions sont approximatives. Une validation complète sans Extra Options reste à effectuer.
