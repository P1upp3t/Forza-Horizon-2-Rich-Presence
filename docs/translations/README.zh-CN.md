# Forza Horizon 2 — Discord Rich Presence

在 Discord 上展示你的爱车、比赛和 Horizon 旅程。

<p align="center"><a href="https://ko-fi.com/puppetzim"><img src="https://ko-fi.com/img/githubbutton_sm.svg" alt="在 Ko-fi 上支持" height="52" /></a></p>

这款免费 Windows 工具可为通过 Azimuth 运行的 Xbox One 版 Forza Horizon 2 提供 Discord 动态状态。所有功能均可免费使用，捐赠完全自愿。源代码不公开。

## 功能

- 车辆卡片显示名称、年份，并将等级和性能指数直接绘制在图片中。
- 每次选择或重新选择车辆时都会重新生成卡片。涂装和轮毂的显示取决于游戏保存的缩略图。
- 显示大致地区、比赛名次、圈数，以及保留两位小数的冲刺赛进度。
- 地图、拍照模式、暂停、嘉年华、车库、升级、喷漆和 Autoshow 状态图标。
- 可直接从工具启动 azimuth.exe：Launch FH2 + Presence 会同时启动启动器和动态状态功能。
- Horizon 风格界面、九种语言，以及每秒 1、2 或 4 次的本地读取。

## 安装

1. 使用顶部链接下载 ZIP，将 rich-presence 文件夹解压到 azimuth.exe 所在目录。
2. 打开 Discord 桌面客户端并登录。
3. 运行 FH2 Presence.exe，选择 Start Presence 或 Launch FH2 + Presence。
4. 如需发布自定义车辆卡片，在 Preferences 中启用 Automatic Thumbnails。

需要 Windows 10/11 x64、Microsoft Edge WebView2 和你自己的游戏安装。无需安装 Python，也无需提供 Discord 密码或令牌。

## 隐私与兼容性

图片上传默认关闭。启用后，仅生成的车辆卡片会作为公开、临时 PNG 上传到 Uguu。不会上传存档、日志或玩家数据库。程序不修改游戏内存或存档。翻译在本地提供；图片和图标可能使用外部服务。

FH2 1.0.0.64：Azimuth 0.9.7 使用 v1.0.0，Azimuth 0.9.9 使用 v1.1.0。在 0.9.9 上已确认车辆、等级/指数、缩略图、地区、暂停和开放世界；比赛功能仍需重新验证。Discord 两次发送至少间隔 15 秒，图片缓存可能造成延迟。地区判断为近似值。尚未完成禁用 Extra Options 后的完整验证。
