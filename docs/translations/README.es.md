# Forza Horizon 2 — Discord Rich Presence

Tu coche, tu carrera y tu viaje por Horizon, en Discord.

Aplicación gratuita para Windows que muestra en Discord tu actividad en Forza Horizon 2 de Xbox One ejecutado mediante Azimuth. Todas las funciones son gratuitas; las donaciones son opcionales. El código fuente es privado.

## Funciones

- Imagen del vehículo con nombre, año, clase e índice de rendimiento dibujados en la tarjeta.
- La tarjeta se vuelve a crear al seleccionar o volver a seleccionar un coche. La pintura y las llantas dependen de la miniatura guardada por el juego.
- Ubicación aproximada, posición, vueltas y progreso de sprint con dos decimales.
- Iconos para mapa, modo foto, pausa, Festival, garaje, mejoras, pintura y Autoshow.
- Abre azimuth.exe desde la aplicación: Launch FH2 + Presence inicia el launcher y la presencia juntos.
- Interfaz inspirada en Horizon, nueve idiomas y lecturas locales de 1, 2 o 4 Hz.

## Instalación

[**Azimuth — Almost There Games**](https://almost-there-games.itch.io/azimuth)

**Juego y licencia:** este proyecto distribuye únicamente la aplicación de Rich Presence. No proporcionamos Forza Horizon 2, DLC, archivos del juego ni claves de licencia. Cada usuario debe obtener su propia copia legítima y cumplir los términos aplicables. Azimuth es un proyecto independiente. Las donaciones apoyan esta aplicación y no compran el juego ni conceden su licencia.

1. Descarga el ZIP con el enlace superior y extrae rich-presence junto a azimuth.exe.
2. Abre Discord para escritorio e inicia sesión.
3. Ejecuta FH2 Presence.exe y elige Start Presence o Launch FH2 + Presence.
4. Para compartir tarjetas personalizadas, activa Automatic Thumbnails en Preferences.

Requiere Windows 11 x64, Microsoft Edge WebView2 y tu propia instalación del juego. No necesitas Python, contraseña ni token de Discord.

## Privacidad y compatibilidad

El envío de imágenes está desactivado por defecto. Al activarlo, solo las tarjetas de vehículos se suben a Uguu como PNG públicos y temporales. No se suben partidas guardadas, registros ni la base de datos del jugador. La aplicación no modifica la memoria ni las partidas. Las traducciones son locales; las imágenes y los iconos pueden usar servicios externos.

FH2 1.0.0.64: usa v1.0.0 con Azimuth 0.9.7 o v1.3.2 con Azimuth 0.9.9. En 0.9.9 se confirmaron vehículo, clase/índice, miniatura, región, pausa y mundo abierto; las carreras necesitan otra validación. Discord tiene un intervalo mínimo de 15 segundos entre envíos; su caché puede retrasar las imágenes. Las regiones son aproximadas. La validación completa sin [Extra Options](https://github.com/RokkuDayo/ForzaHorizon2_ExtraOptions) aún está pendiente.
