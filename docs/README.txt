FH2 DISCORD PRESENCE v1.4.1

A free companion for Forza Horizon 2 running through Azimuth.
Requires Discord desktop and your own legitimate game installation.
Python is not required.

GETTING STARTED
Keep rich-presence next to azimuth.exe. Open FH2 Presence.exe, check your
preferences and start Presence when ready. Closing the panel can leave the
app in the tray; choose Exit app to quit. Starting Presence remains manual.
After first-time setup, the panel opens in the Windows tray by default. Turn
off Start in tray under Preferences > Behaviour and history to change this.

COMPATIBILITY
This build targets Azimuth 0.9.9 with FH2 1.0.0.64. For Azimuth 0.9.7, use
legacy v1.0.0. Future Azimuth versions and the recent Extra Options update
are not confirmed compatible. Racing features on 0.9.9 still need a fresh
check. A compatibility warning is a reason to review the release notes.

PREFERENCES AND PRIVACY
Save preferences applies the current form. Saving a named profile also
applies it. Restore defaults first shows the proposed changes, fills the
form after confirmation, and waits for you to save preferences.

Discreet mode shows only the game, without vehicle, region, race or timer.
Return to previous profile restores the earlier privacy and timer choices,
keeping your other current preferences. The privacy example in Preferences
is local and sends nothing to Discord.

Thumbnail hosting is optional and off by default. Enabling it uploads car
cards as public temporary images. Hiding the vehicle prevents new uploads;
already-started uploads may finish and existing links cannot be revoked.
Optional local session history can retain car names even when hidden from
Discord. Preference exports exclude game paths, images and history.

UPDATING
Stop Presence and exit the app before replacing files. Keep config.json and
runtime to retain preferences and local data. Assisted updates verify the
official download and offer a local backup/return option after installation.

QUESTIONS
Nothing on Discord? Open Discord desktop, sign in, enable activity sharing,
load FH2 through Azimuth and start Presence. Review the connection panel.
Discord sends are at least 15 seconds apart; 1/2/4 Hz controls local reads.
An old car image can be cached. Reselect the vehicle so the game can save a
new thumbnail, then allow time for hosting and Discord to refresh.

The app remembers window position and size separately for full and compact
views, fitting the window to an available screen if a monitor is removed.
Opening the app again restores the existing panel instead of opening another.
