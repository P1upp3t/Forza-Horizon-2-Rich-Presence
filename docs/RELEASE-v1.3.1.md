## New in v1.3.1

- Compact mode puts the car preview, connection status and main controls in a smaller window. Use Full view whenever you want the complete panel back.
- After leaving painting or upgrades, the panel warns when no newer saved thumbnail has appeared. If you changed the car's appearance, try reselecting it so the game saves a fresh image. Discord's image cache can still take a little longer to refresh it.
- With local history enabled, closing Azimuth shows a short recap of the recorded session time and cars you used. Stopping Presence manually doesn't mark the game session as finished. History stays on your PC and is off by default.

Includes everything from **v1.3.0**: the Windows tray, Presence profiles, session timer, delivery preview, first-use setup and optional local history.

## Compatibility

For **Azimuth 0.9.9 with FH2 1.0.0.64**. Racing support on 0.9.9 still needs a fresh check, and compatibility with future Azimuth versions or the recent Extra Options update isn't confirmed. Use legacy **v1.0.0 for Azimuth 0.9.7**.

Discord updates have a minimum 15-second interval. New paint or wheel pictures depend on a thumbnail saved by the game.

## Download and install

Download **FH2-Presence-v1.3.1-Windows-x64.zip** below. You can update directly to this version. Stop Presence and choose **Exit app** before updating; closing the window can leave it in the tray. Extract `rich-presence` next to `azimuth.exe`, and keep your existing `config.json` and `runtime` folder.

Requires Windows 11 x64, WebView2 and Discord desktop. Python is not required. 

All features and downloads are free. Source code remains private. No game, DLC, game files, license keys or personal configuration are included. Automatic thumbnail hosting and local history are off by default. If you enable images, car cards use public, temporary Uguu links; existing links cannot be revoked by the app.
