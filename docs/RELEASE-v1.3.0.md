## New in v1.3.0

- Keep the app in the Windows tray while you play. You can reopen the panel, stop Presence or quit from the tray menu. With Minimize to tray enabled, closing the window keeps the app running; use Exit app to close it completely.
- Switch between Full, No location and Game only profiles, or save your own privacy and timer settings.
- Show the session timer in Discord, or hide it if you prefer.
- See the next Presence update separately from the last activity Discord accepted. This makes it easier to understand why a change hasn't appeared yet; images can still take longer because of Discord's cache.
- First-use setup helps you choose your Azimuth folder and checks that Discord is open.
- Optional local history keeps the recorded session time and cars used. It's off by default, stays on your PC and keeps up to 50 sessions. You can delete it from the panel.

## Compatibility

For **Azimuth 0.9.9 with FH2 1.0.0.64**. Racing support on 0.9.9 still needs a fresh check, and compatibility with future Azimuth versions or the recent Extra Options update isn't confirmed. Use legacy **v1.0.0 for Azimuth 0.9.7**.

Discord updates have a minimum 15-second interval. New paint or wheel pictures depend on a thumbnail saved by the game.

## Download and install

Download **FH2-Presence-v1.3.0-Windows-x64.zip** below. Stop Presence and choose **Exit app** before updating; closing the window can leave it in the tray. Extract `rich-presence` next to `azimuth.exe`, and keep your existing `config.json` and `runtime` folder.

Requires Windows 11 x64, WebView2 and Discord desktop. Python is not required. You can verify the ZIP with `SHA256SUMS.txt`.

All features and downloads are free. Source code remains private. No game, DLC, game files, license keys or personal configuration are included. Automatic thumbnail hosting and local history are off by default. If you enable images, car cards use public, temporary Uguu links; existing links cannot be revoked by the app.
